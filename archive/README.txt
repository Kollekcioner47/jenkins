Материалы прежней версии курса.

Эти файлы не используются на занятиях. Они оставлены только для истории:
в новой версии курса их содержание полностью заменено, а всё полезное
и всё ошибочное разобрано в новых практиках с пометками ИСПРАВЛЕНО.

ЧТО ЗДЕСЬ ЛЕЖИТ И ЧЕМ ЗАМЕНЕНО

  1_install_jenkins.txt
      Конспект установки Jenkins: ключ репозитория jenkins.io.key
      (с 2023 года не работает), Java 17 (сегодня нужна 21),
      команда service jenkins status вместо systemctl.
      Заменено практикой 1_install.txt.

  2_administration_jenkins.txt
      Четыре строки без содержания: «показать настройки Jenkins»,
      «показать апгрейд», «wget version».
      Заменено практикой 2_administration.txt (пользователи, права,
      безопасность, плагины, журналы, обслуживание).

  6_deploy_from_github.txt
      Практика была построена на облачном GitHub и на плагине
      Publish over SSH. При отсутствии белого IP вебхук из облака
      в лабораторию не дойдёт, а плагин Publish over SSH давно
      не поддерживается.
      Заменено практикой 6_gitea.txt (свой Git-сервер внутри сети)
      и практикой 11_deploy.txt (выкат через ssh-agent и rsync).

  files-for-practics/index.html
      Страница сайта, свёрстанная тегами <font> и атрибутом bgcolor.
      Оба удалены из HTML много лет назад.
      Заменено файлами files/www/index.html и files/www/index-v2.html,
      где добавлены маркеры подстановки номера сборки, на которых
      построена проверка выката.

ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ ДЛЯ ТОГО, КТО ОТКРОЕТ ЭТИ ФАЙЛЫ

Тексты в каталоге archive/ сохранены как есть, включая неправильные
команды, устаревшие пароли и опечатки. Копировать из них команды
нельзя: часть команд не работает, а часть открывает лишний доступ
(например, включение анонимного чтения в Jenkins ради работы триггера).


ФРАГМЕНТЫ ПРЕЖНИХ ТЕКСТОВ, НА КОТОРЫЕ ССЫЛАЮТСЯ ПОМЕТКИ ИСПРАВЛЕНО

Прежние версии практик 3-10 были заменены новыми на месте, поэтому
целиком их в этом каталоге нет — они остались только в истории версий
файлов. Чтобы пометки ИСПРАВЛЕНО можно было проверить, ключевые места
прежних текстов приведены здесь дословно.

  Практика 3 (задания):
    «чтобы не допускать разрастание папки нужно в свойствах билда
     настроить discord old builds» — пункт в Jenkins называется
     Discard old builds, слова Discord в интерфейсе нет.
    «Заходим на веб-консоль и создаём job "FirstJob" / в разделе build
     выбираем execute shell» — раздела Build в форме задания нет,
     шаги сборки добавляются в Build Steps.
    «echo "Hello, Wolrd!"» — опечатка в тексте журнала.

  Практика 5 (CLI):
    «клиент скачивается в админке Jenkins - Menage Jenkins -> Jenkins CLI»
     — меню называется Manage Jenkins.
    «echo -n %token% > servicetoken» — файл с токеном создавался без
     ограничения прав.

  Практика 7 (триггеры):
    «Ставим галочку Pool SCM в разделе Build Triggers» — правильно
     Poll SCM.
    «Triger remotely» — правильно Trigger builds remotely.
    «#НУЖЕН белый IP, переписываю на GitLab» — плана переписать не было:
     в новой версии для этого стоит свой Git-сервер Gitea.

  Практика 8 (параметры):
    параметр объявлен как «name: FOLDERNAME», а в шаге сборки
     использовался «ls -l $FILENAME»: имя параметра и имя подстановки
     не совпадали, задание запускалось с пустой переменной.

  Практика 9 (Groovy):
    «Jenkins.intance.getItemByFullName("gh_deploy")» — правильно
     Jenkins.get() или Jenkins.instance.
    «println {"Hello DevOps from Jenkins!"}» — фигурные скобки создают
     замыкание, которое никто не вызывает.
    «if{it.result == Result.SUCCESS}» — в условии нужны круглые скобки,
     а сам Result требует import hudson.model.Result.
    «//Вместо SUCCESS(успешные) можно FILURE(неудачные)» — опечатка.

  Практика 10 (конвейеры):
    «agent nay» — правильно agent any.
    «echo 'Building...."» — одинарная кавычка открыта, двойная закрыта.
    задание «Pipeline_job_2» объявлялось дважды, а следующее упражнение
     снова создавало уже существующее задание.
    «agent { docker { image 'python:3.7' } }» — образ снят с поддержки.

Прежний текст практики 6 (развёртывание из GitHub) и практик 1-2
доступен полностью: см. файлы в этом каталоге.
